Smart Manhole Monitoring System 🚧

An IoT and AI-based Smart Manhole Monitoring System designed to improve manhole safety through real-time monitoring and intelligent event classification.

Features

- Real-time tilt and movement detection.
- Gas level monitoring.
- ESP32-based sensor data collection.
- Firebase Realtime Database integration.
- Live web dashboard.
- AI-based event classification.
- LED and buzzer alerts.

Hardware Components

- ESP32 DevKit V1
- MPU6050 Tilt Sensor
- MQ135 Gas Sensor
- LED
- Buzzer
- BC547 Transistor

Technologies Used

- Python
- Machine Learning (Random Forest)
- Flask API
- Firebase Realtime Database
- HTML, CSS, JavaScript
- Arduino IDE

AI Classification

The model classifies events into four categories:

- Normal
- Accidental
- Suspicious
- Maintenance

Note: The current model is trained on synthetic sample data. Real-world testing is required for validation.

Future Scope

- GPS-based location tracking.
- SMS and emergency notifications.
- Battery backup.
- Real-world dataset training.
- Improved waterproof protection.

Project Objective

To develop a smart monitoring system that helps detect unusual manhole activity and potential gas hazards, supporting safer and smarter infrastructure.
